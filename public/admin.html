Проверяем подключение…

Для синхронизации через Discord API добавь DISCORD_BOT_TOKEN и DISCORD_GUILD_ID в .env. Для уведомлений о новых тикетах и событиях настрой DISCORD_WEBHOOK_URL. Токен бота хранится только на сервере.

Модерация галереи

Безопасность и состояние

Интеграция: Discord REST API для статуса сервера, webhook-уведомления и управление событиями/галереей.

OAuth2: вход через Discord, проверка state и серверный обмен кода.

Доступ: список разрешённых Discord ID хранится только на сервере.

Сессии: SQLite-хранилище, HttpOnly cookie, SameSite=Lax; Secure включается в production.

Запросы: CSRF-токен на административные изменения, лимиты запросов, Helmet и валидация полей.

Журнал: публикации, мероприятия, изменения статуса заявок и резервные копии записываются в аудит.

Важно: для публикации включи HTTPS и используй сильный SESSION_SECRET. Никогда не загружай .env в Git.
